# DD2 — Danial 3D Personal Portfolio

Premium cinematic 3D personal portfolio for Danial.

## Vision
- Black + gold cinematic identity
- Interactive 3D hero experience
- Smooth scroll-driven storytelling
- Personal intro, skills, work, journey, and contact
- Responsive desktop/mobile experience
- Premium motion without visual clutter

## Stack
Next.js + React + TypeScript + Tailwind CSS + Three.js / React Three Fiber + Motion + Lucide.

## Sections
Hero / About / Skills / Selected Work / Journey / Contact.

## Design
Deep black, restrained gold accents, glass surfaces, subtle glow, depth, parallax, cinematic lighting, and camera-like transitions. Avoid generic templates, clutter, excessive gradients, and unnecessary UI chrome.
